# 📊 Data Analytics Project

## 📌 Overview
This project demonstrates an end-to-end data analytics workflow, from raw dataset to business insights and professional presentation.

The objective is to analyze the data, identify patterns, and present insights using visualizations and dashboards.

The project includes:
- Loading dataset using Python
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- SQL analysis using PostgreSQL
- Interactive Power BI dashboard
- Analytical report
- Presentation created using Gamma

This project highlights practical skills in data analytics and visualization.

---

## 📂 Dataset
The dataset contains structured data related to customers, products, and purchases.

Example columns:
- customer_id
- age
- gender
- location
- purchase_amount
- category
- item_purchased
- review_rating
- subscription_status
- discount_applied

The dataset is used to analyze customer behavior and purchasing trends.

## 🔎 Project Steps

### 1. Data Loading (Python)
- Import dataset using pandas
- Inspect structure and data types
- Identify missing values

### 2. Exploratory Data Analysis (EDA)
- Summary statistics
- Data distribution
- Correlation analysis
- Identify trends and patterns

### 3. Data Cleaning
- Handle missing values
- Remove duplicates
- Fix data types
- Prepare dataset for analysis

### 4. SQL Analysis
SQL queries were written to answer business questions such as:
- Top selling products
- Revenue by category
- Customer spending behavior
- Average product rating
- Impact of discount on purchases

Database used:
- PostgreSQL

### 5. Power BI Dashboard
An interactive dashboard was built to visualize:
- Revenue insights
- Customer segmentation
- Product performance
- Key performance indicators (KPIs)

### 6. Report
A report summarizing:
- Project objective
- Methodology
- Key insights
- Recommendations

### 7. Presentation (Gamma)
A professional presentation explaining:
- Problem statement
- Analysis workflow
- Dashboard results
- Key findings
