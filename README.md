# 📌 Overview

This project demonstrates a complete **end-to-end data analytics workflow**, transforming raw customer purchase data into actionable business insights.

The analysis pipeline includes:

- 📥 Data loading and preprocessing
- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data cleaning and transformation
- 🗄️ SQL business analysis using PostgreSQL
- 📈 Interactive Power BI dashboards
- 📝 Analytical reporting
- 🎤 Business presentation using Gamma

The project highlights practical skills in:

- Data Analytics
- Business Intelligence
- SQL Analysis
- Data Visualization
- Dashboard Development
- Insight Generation

---

# 🎯 Project Objectives

- Analyze customer purchasing behavior
- Identify sales and revenue patterns
- Discover high-value customer segments
- Evaluate product performance
- Build interactive dashboards
- Generate data-driven business insights

# 📊 Dataset Description

The dataset contains structured customer purchase information.

### Example Variables

| Variable | Description |
|---|---|
| customer_id | Unique customer identifier |
| age | Customer age |
| gender | Customer gender |
| location | Customer location |
| purchase_amount | Purchase value |
| category | Product category |
| item_purchased | Purchased product |
| review_rating | Customer rating |
| subscription_status | Subscription information |
| discount_applied | Discount usage |
